# 持续筹码赛制：下注与动态改航费用草案

> 历史讨论稿：2026-10-09 已汇总确认为 [标准牌局规则 v1.0](standard-rules.md)。当前采用反向改航及实际改航顺位 5%→10% 费率；本文的顺向名单、候选参数和待定表述保留为讨论记录，不作为现行规则。

状态：12 局、前六局底注 1／后六局底注 2 及持续筹码规则已接入独立对战引擎；改航费率仍在比较。牌库沿用当前 27 张牌、两张底牌、三张公共牌、最终至少一张底牌的约定。

本草案把每局发放补给、转换得分的旧机制，改为整场持续流转的筹码机制。此前重置筹码的模拟不能证明本草案的破产速度、资金分布或费用平衡。

## 一整场的资金与长度

采用固定局数原型：五人各带入 100 枚游戏筹码，整场最多 12 局，不补充、不借贷、不在局间重置。只剩一人持有筹码则提前结束，否则第 12 局结算后筹码最多者获胜；同分并列。

每局起始玩家移至下一位仍持有筹码的玩家。前 6 局底注每人 1，后 6 局每人 2。12 局及这套底注时序已确认；改航费率仍需比较。固定局数赛制无需通过不断提高底注强制在某时刻淘汰全部玩家。

当前局中余额为零不等于已出局：玩家可能已经全下，仍可能赢回筹码。只有本局全部结算后余额仍为零，才不参加下一局。所有本局奖金和退款均按既定时点归还，已锁定但尚未结算的奖金不能提前拿来下注或付改航费；未获跟注的超额下注在下注轮关闭时退回本人可用余额。

每局仍是五轮操作：底注、一注、二注、改航、三注。三张公共牌分别在一注、二注、三注之前揭开。所有底牌保持隐藏，直到正式摊牌；全下不提前亮牌。

## 下注采用底池限注

这是一套候选方案，选择底池限注是为了让下注规模随争夺中的筹码增长，并保留自由选择下注大小的空间。固定限注也可作为后续控制组，无限注暂不作为默认。

设本局底注为 a。每个下注轮重新开始计算该轮目标额，规则如下：

| 项目 | 规则 |
| --- | --- |
| 筹码单位 | 1，所有金额为整数 |
| 没人下注时 | 可以过牌；首次正常下注至少 2a |
| 有人下注时 | 可以跟注、弃牌，或在拥有加价权时加注 |
| 最小完整加注 | 至少等于本轮上一次完整加价的幅度；初始下限为 2a |
| 最大下注/加注 | 受底池限注上限和自己剩余筹码共同限制 |
| 加注次数 | 不另设次数上限；本轮不能凭空增加筹码 |
| 全下例外 | 余额不足最低开注，或不足“跟注额＋最低完整加价”时，可在具有相应下注/加价权的前提下投入全部余额；不必凑够最低额，但不得越过底池最高额 |

如果当前需要跟注 C，行动前可计入的常规下注池为 P，则本次最多新增投入：

**min(剩余筹码，P + 2C)**。

这个上限不授予加价权：只有仍有对手可响应且本人拥有加价权时，才能用它计算加注。加价权尚未重新开放者最多只能新增投入 min(剩余筹码，C)，不能借全下绕过限制。

其中先跟 C，再最多额外加 P+C。目标下注额还要加上自己本轮已经投入的金额，不能把“本次新增投入”误认为“本轮累计投入”。无人下注时 C=0，因此最高开注为 P。

例如行动前池为 20、需要跟 6：可以先跟 6，跟后池为 26，再最多加 26，本次最多投入 32。实际投入仍受余额限制。若本次选择的加价小于最低完整加价，只有确实用尽余额的全下才合法；正常玩家不能任意用小额加价拖延。

P 包括常规底注及下注，按当前行动状态计入对手等待响应的下注；不包括改航附加池，也不包括已锁定给单个玩家的独得池。这样改航费用不会同时放大第三轮加注上限。

### 全下与重新开放加价权

- 完整加价发生后，其他尚有余额者重新获得响应和加价机会。
- 不足完整加价幅度的全下，不改变“上次完整加价幅度”。
- 对已经下注或跟注过的人，若后来面临的新增目标额累计不足一次完整加价，他只能跟或弃；达到完整加价幅度时才重新获得加价权。应记录每名玩家上次行动时的目标额，不能仅用全桌一个开关处理累计短全下。
- 尚未行动的人，及此前只过牌、尚未面对下注的人，仍保留加价权。
- 本草案明确采用“短开注不做补齐”：最低开注为 2、有人先全下 1 时，有加价权者可跟 1，或加到至少 3（在当前 1 上增加最低完整幅度 2）。先前过牌的人也可这样加价。避免把不足开注的全下误当作一次完整开注。

例如 A 开注 10，B 全下到 15：B 只增加 5，没有完整加价，若没有其他加价，A 不能因为再次轮到自己就继续加注。若之后多名短全下把目标累计推到 20，A 面临的新差额达到 10，才重新获得加价权。

无待跟注额时只能过牌或合法下注，不主动弃牌；全下玩家保留到摊牌，不再执行弃牌。只有一名玩家有余额时，不允许向无人能够跟注的新边池下注；若此前仍有待响应的全下注额，该玩家仍须先跟注或弃牌。

## 筹码不足时如何处理

| 情况 | 处理 |
| --- | --- |
| 局前为零 | 已于上一局结算后出局，不再发牌 |
| 有筹码，但不足底注 | 投入全部余额，作为底注全下；仍发牌和保留获胜资格 |
| 余额不足跟注 | 可弃牌，或投入全部余额全下；按实际投入确定奖池资格 |
| 余额足以跟注，但不足“跟注额＋最小完整加价” | 可跟、弃，或在拥有加价权且不超过最高额时短额全下 |
| 改航费用不足 | 不能改航，保留已有牌局资格；不允许部分支付或赊账 |
| 恰好付完改航费 | 可以发动；随后余额为零，作为全下者继续参与已有资格的结算 |

底注也是常规贡献的一部分。例如三人底注为 2，实际只能交 1/2/2，则三人共同竞争主池 3，另两人竞争边池 2。不能因第一人未交满底注就直接淘汰，也不能让其无条件赢取全部底注。

例如需要跟注 6、最小完整加价为 10，完整加注需新增至少 16；余额 12 的玩家若有加价权且未超过底池上限，可以全下 12，其中 6 是跟注、6 是不足完整幅度的加价。

## 主池与边池

“底注＋常规下注”进入每个人的有效贡献账本。不同全下额度按贡献层建立主池和边池；弃牌者已投入的钱留在相应层，但失去获奖资格。未获任何对手跟进的超额下注退回，不为自己制造一个奖池。

例如 A 全下 10，B、C 各投入 30：主池为 30，三人都可争夺；边池为 40，仅 B、C 可争夺。即使 A 牌最大，也只拿主池。B、C 再比较各自牌型决定边池归属。

后续普通下注可能形成新的边池，但每个人只能竞争自己投入覆盖的层。单个池只有一名未弃牌资格者时，该池归该玩家；其他争夺中的池继续进行，不能因此提前结束全部牌局。

## 动态改航报价

费用与“当前有多少可争夺筹码”相关，再加入顺位溢价，不直接照抄旧版固定 2–6。

二注结束后先退还未被跟进的超额下注，识别当前主池与边池。在改航窗口开始时冻结以下信息：

1. 所有未弃牌且尚有余额的玩家，按本局行动顺序形成改航名单；已经全下者不占操作顺位。
2. 对每位玩家 i，计算其有资格竞争且至少有两名未弃牌者仍在争夺的常规下注池总额 E_i。个人已锁定的独得池不计入。
3. 名单长度为 m，玩家顺位为 r。若 m≥2，比例为 `5% + 5% × (r−1)/(m−1)`；若只有一人可以操作，比例取 10%。
4. **报价 c_i = max(本局底注 a，向上取整(E_i × 比例))**。所有金额按 1 枚取整。

这组 5%—10% 是对照参数，不是已确定的平衡结论。目标是通过顺位费用补偿先手，尽量让先手获得小幅净收益优势。它让最后一位最多支付首位两倍的比例；仅三人可操作时使用 5%、7.5%、10%，不是取五人报价表的前三项。实验可分别调节首位、末位比例，中间顺位线性插值；只有一人可操作时取末位比例。

当可争夺池 E=40、底注为 1、五人均有余额时，费用为 **2、3、3、4、4**；E=80 时费用为 **4、5、6、7、8**。金额随争夺规模变化。

12 局版已比较 5%—5%、5%—10%、3%—15%、2%—20%，并对 3%—15% 做独立种子验证。后者相对基准改善先手收益，但未确认达到先手略优；许多小奖池仍因取整及最低底注变成全员同价。费率继续保留为待定参数，详见[本轮实验结论](../reports/persistent-validation/findings.md)。

名单和全部报价同时冻结。前人放弃、付不起、付费或改牌，都不改变后面人的费用与顺位；本轮改航费不加入 E，避免费用递归上涨。资金只能来自本人尚未投入的余额。

若某玩家已没有任何仍在争夺且自己有资格参与的常规池，则没有改航机会，不收取费用。若所有池均已确定归属，则直接结算。

已全下者不能再付费改航，但公共牌改变仍会影响他。仅一名玩家有余额、其他玩家已全下时，只要仍有争夺中的池且他能足额付款，就可以改航；后续没有可对赌者则直接完成揭牌与结算。

## 改航费进入哪里

**改航费留在本局奖金中，但不算作任何人的普通下注贡献。** 不用这笔费用补跟注，不增加边池资格，也不提高下一轮下注上限。

为避免短码玩家无条件取得其未覆盖的大额边池奖励，采用独立的“改航附加池”账本：

1. 窗口开始时，对每个可改航者找到自己有资格且至少两名未弃牌者竞争的最高层常规池。
2. 该玩家的改航费归入附属于该层的费用池，资格名单在窗口开始时冻结。具有同一名单的费用可合并。
3. 后续下注不会扩充这份资格名单，也不会把旧费用搬到后来形成的更高边池。后续弃牌会失去领取资格。
4. 摊牌前，同一资格名单的常规贡献层合并，同一资格名单的附加费用合并；常规与附加仍分开结算，避免程序拆层或收费笔数改变余筹分配。每个合并后的池在其资格名单内比较牌型；只有一人仍有资格则直接获得。平局先均分，无法均分的余筹从本局起始玩家开始按行动顺序，在该池并列赢家中每人补一枚，直到分完。本草案以此替代旧原型的余筹弃置，保持整场筹码总量不变。

例如 A、B 各常规投入 40 且仍有余额，C 全下 10：主池 30，A/B 边池 60。底注为 1、A 先改航时，其报价为向上取整(90×5%)＝5；若 A 付款，则另外形成 **A/B 才有资格争夺的附加池 5**。A 的常规贡献仍为 40，C 仍只能争主池。后续 A、B 再加注时，旧附加池不改变资格。

不能把费用放进只有缴费者一人必得的层，否则相当于无成本改牌，所以报价和挂费目标都只取仍有至少两人争夺的池。后续一方弃牌导致另一方独得属于正常对局结果。

“无待跟注时不主动弃牌”与“全下者保留到摊牌”共同保证附加池不会全部失去资格者：窗口开始时，所有仍能继续下注的玩家都已跟齐二注，包含在相应最高争夺层；层外的较低全下者不会再发起下注，无法迫使最后一个层内资格者退出。

## 下一轮应验证的指标

- 第几局首次淘汰、12 局后剩余人数、是否过早只剩一人。
- 玩家筹码分布、领先者胜率、落后者翻盘机会、资金集中程度。
- 每局最高下注、全下与边池出现频率、改航阶段仍有余额的人数。
- 动态费用下各顺位实际改航率、费用负担和净收益。
- 有筹码者能改变公共牌、全下者无法响应带来的影响。
- 固定限注与底池限注对上述指标的差异，而不仅是单局胜率。
