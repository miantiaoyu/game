# 改航反向行动：12 局对照试验

> 历史试验记录：2026-10-09 已确认反向改航＋5%→10% 费率，完整执行规则见 [标准牌局规则 v1.0](standard-rules.md)。以下保留定稿前的实验设计与结果边界。

状态：已完成四组各 1,000 场的完整轨迹对照，反向顺序保留为下一版试玩候选。[结果与边界](../reports/reverse-order/findings.md)：反向＋原 5%—10% 费率提高了这组机器人中原下注先手的盈利频率，但未确认净筹码优势；仅五人子组也尚未确认优势。12 局及筹码规则沿用现有约定。

## 顺序

以本局起始玩家为 A，其余依次为 B、C、D、E：

| 阶段 | 原顺序 | 候选顺序 |
| --- | --- | --- |
| 底注 | 全员投入 | 全员投入 |
| 一注 | A→B→C→D→E | A→B→C→D→E |
| 二注 | A→B→C→D→E | A→B→C→D→E |
| 改航选择 | A→B→C→D→E | E→D→C→B→A |
| 三注 | A→B→C→D→E | A→B→C→D→E |

表中为每轮首次行动顺序；加注后按原下注方向重新响应。弃牌者不再操作，已全下者不占改航顺位，名单在改航窗口开始时冻结。对冻结的可操作名单整体反转，不复活弃牌者或全下者。每名可操作玩家仍只有一次改航或放弃机会，后人可以再次替换同一位置。

费用仍跟随实际改航顺位：先改者便宜，后改者贵。以 3%—15%、五人可争夺池均为 40 枚为例，原顺序 A/B/C/D/E 的报价为 2/3/4/5/6；反向后 E/D/C/B/A 的报价为 2/3/4/5/6。因此本轮比较包含顺序与费用重新分配的共同效果，不能叫作只改变信息量的实验。没有引入新的费率。

## 要测的量

分别固定 5%—10% 和 3%—15% 两种费率，每种各跑原顺序、反向顺序的完整 12 局。各组每人初始 100 枚，前六局底注 1／后六局底注 2，底池限注、主边池与费用附加池均沿用当前规则。同编号整场共用随机种子及初始行动位；每组的后续筹码、淘汰与牌局自然分化。

位置按每局开始时的下注顺位定义：即使本局首位早早弃牌或全下，也不能从首位样本中删掉。主要指标为“原下注首位减末位”的净筹码与单局盈利率，每场先对其各局取均值，再跨独立整场计算区间。正数偏下注先手，负数偏下注后手；同编号两组再作配对差，观察反向改航是否向原下注先手移动。

同时按开局人数分层，记录各下注顺位的收益、盈利率、进入改航名单比例及实际费用；统计整场淘汰、提前结束和资金集中。不能将整场中的 P1/P2 身份当作永久先手/后手，因为起始玩家逐局轮换。

此前的窗口快照对照只反转某一窗口再完成当前局，本轮则让整场持续使用候选顺序。两类结果回答不同问题：前者控制当前状态，后者包含顺序影响后续筹码和参与者的长期效应。

## 改航动作作为信息

主动换掉哪张牌、是否愿意支付费用、选择不换，都可能透露手牌偏好。换入牌由随机抽取产生，不能把随机换入牌本身当作玩家选择的目标牌。

当前机器人会使用最新公共牌、公开弃牌和奖池重新估值，但不记录谁换掉哪张、谁放弃的行为历史，也不根据这些动作推断对手底牌。它也不预测后人覆盖。因而本轮能测公共牌变化、最后改航权、费用与后续下注的共同效果，不能完整量化读懂动作意图的价值。

反向改航让原下注先手较晚选择改航，并在仍能参与时获得最后改航权；三注仍按原顺序，原下注后手仍能看到前人的最终下注动作。二者不能未经实测就认定完全抵消。
