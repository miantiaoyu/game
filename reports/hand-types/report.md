# 牌型频率探针

这是发牌分布分析，不是策略对战，也没有模拟改航、下注或撤退。种子为 `20261008`，随机样本 `100,000` 局面。牌库为四色各 1—9，不含环绕顺子；1 仅为最小点数。

## 推荐方案：1 张私牌 + 2 张公共牌，六组选最强

以下才是推荐规则中**最终选出的牌型**频率。每次无放回抽取 5 张不同牌，前 2 张为私牌、后 3 张为公共牌；对子可以由两张公共牌组成，仍必须使用私牌作第三张牌。以下是蒙特卡洛估计，不能称为精确枚举，也不是发生过玩家操作后的实际频率。

| 牌型 | 次数 | 比例 |
| --- | ---: | ---: |
| 同花顺 | 2,245 | 2.2450% |
| 三条 | 2,959 | 2.9590% |
| 同花 | 19,953 | 19.9530% |
| 顺子 | 21,062 | 21.0620% |
| 对子 | 36,744 | 36.7440% |
| 散牌 | 17,037 | 17.0370% |

## 基础对照：无角色的随机三张牌，精确枚举

共 C(36,3) = 7,140 组。不区分私牌；所有对子都算对子。此表用来理解牌库构成，不能直接当作游戏最后选出的牌型分布。

| 牌型 | 次数 | 比例 |
| --- | ---: | ---: |
| 同花顺 | 28 | 0.3922% |
| 三条 | 36 | 0.5042% |
| 同花 | 308 | 4.3137% |
| 顺子 | 420 | 5.8824% |
| 对子 | 1,728 | 24.2017% |
| 散牌 | 4,620 | 64.7059% |

## 可选变体：对子必须包含私牌，基础精确枚举

共 36 × C(35,2) = 21,420 个带角色组合。对子必须包含私牌，但还没有“2 私牌、3 公牌选最优”的选择收益。

| 牌型 | 次数 | 比例 |
| --- | ---: | ---: |
| 同花顺 | 84 | 0.3922% |
| 三条 | 108 | 0.5042% |
| 同花 | 924 | 4.3137% |
| 顺子 | 1,260 | 5.8824% |
| 对子 | 3,456 | 16.1345% |
| 散牌 | 15,588 | 72.7731% |

此条件不属于推荐默认规则；默认规则中，固定一私两公的边际频率与上面的无角色三张表一致。条件会产生“看起来是一对，但算散牌”的特殊情况，故仅供规则取舍参考。

## 五张全用方案：精确枚举

共 C(36,5) = 376,992 组。所有五张都用，所以随机 2 私牌 + 3 公牌的边际牌型分布与此表相同；各玩家共享公牌，彼此牌型并不独立。展示沿用熟悉的葫芦高于同花的顺序，仅作候选对照；这副短牌库中同花比葫芦稀有，若采用五张方案应另行决定是否调整顺序。

| 牌型 | 次数 | 比例 |
| --- | ---: | ---: |
| 同花顺 | 20 | 0.0053% |
| 四条 | 288 | 0.0764% |
| 葫芦 | 1,728 | 0.4584% |
| 同花 | 484 | 0.1284% |
| 顺子 | 5,100 | 1.3528% |
| 三条 | 16,128 | 4.2781% |
| 两对 | 36,288 | 9.6257% |
| 对子 | 193,536 | 51.3369% |
| 散牌 | 123,420 | 32.7381% |

同一批随机布局中，有 16.01% 的布局在五张方案下是“仅公牌组成对子或三条，私牌仅为踢脚牌”。两张私牌虽然参与五张比较，却未参与决定该牌型的重复点数组合。这是对五张方案结构的观察，不代表该玩家一定与对手平手。

## 口径与边界

- 每个精确表的各类互斥：同花不包含同花顺，顺子不包含同花顺。
- 不比较玩家、不产生获胜者、不报告胜率。最终最优三张的分布会受改航、撤退及对手策略影响，这里没有建模。
- 100,000 独立样本下，单个比例最保守的近似 95% 误差半宽为 0.31 个百分点；稀有牌型的误差需按实际频率计算。
- 单张私牌加两个公牌共六种候选组合，候选相互重叠，不可按六次独立抽牌估算。
- 脚本内对枚举总数、各基础牌型计数、低点数组牌例子和私牌对子条件进行了确定性校验。

复现：`python3 -m simulation.hand_type_probe --samples 100000 --seed 20261008 --output reports/hand-types`
